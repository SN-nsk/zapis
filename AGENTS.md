# Инструкции для работы с кодом

## Обязательный регламент

При написании, изменении, отладке, анализе и проверке кода этого репозитория **всегда использовать** регламент [«Поиск причины ошибки»](docs/skills/poisk-prichiny-oshibki.md).

- При любой неисправности сначала исследовать и воспроизвести её, установить и подтвердить первопричину. До завершения диагностики не предлагать исправления.
- Соблюдать четыре этапа скилла строго последовательно: найти причину → сравнить с рабочим → проверить одну гипотезу → выполнить одно точечное исправление и полный контроль.
- До исправления написать воспроизводящий сбой тест, когда это технически возможно; после — выполнить подходящие тесты и проверку регрессий.
- После трёх безрезультатных попыток остановиться, вернуться к обсуждению подхода; не выполнять четвёртую попытку автоматически.
- Даже при разработке новой функции применять дисциплину проверки: предварительно читать актуальный код и зависимости, проверять результат и исследовать ошибки по указанному регламенту.
- Не выдавать непроверенные изменения за работающие. Перед передачей результата самостоятельно провести доступные проверки; ограничения явно указывать.
- Объяснения для Сергея давать простым русским языком. Не подменять подтверждённые причины предположениями.

**Важно:** здесь размещены файлы сайта и сборки APK. При работе с исходниками Android-приложения «Мастерио» тот же регламент необходимо включить в корневой AGENTS.md репозитория исходников, когда он станет доступен.
